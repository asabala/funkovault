## Progressive Disclosure

Funko Vault should keep screens clean and focused.

If information is helpful but not required immediately, use progressive disclosure instead of taking up permanent screen space.

Examples:

* Use an information icon to explain complex fields.
* Use tap or hover popups for helper text.
* Use tooltips for short explanations.
* Use dialogs or bottom sheets for longer guidance.
* Avoid large instruction blocks unless the user truly needs them.

The goal is to keep the main workflow fast, clean, and easy to use while still making help available when needed.

### Rule

If guidance can be hidden behind an info icon without hurting usability, hide it behind an info icon.

### Examples

Edition / Sticker
Info popup explains Common, Chase, Glow, SDCC, NYCC, LE, Signed, and other collector identity options.

Vault Health
Info popup explains how Atlas calculates the score.

Collector Identity
Info popup explains why variant, exclusive, event sticker, limited edition, and signature matter.

Atlas should provide help without crowding the collector experience.
