# Atlas Definition of Done

A feature is not complete because it compiles.

A feature is complete when it satisfies all Atlas engineering standards.

---

## Architecture

□ Architecture reviewed

□ Existing engines evaluated

□ No duplicate responsibilities introduced

---

## Implementation

□ Engine completed

□ Service completed

□ UI connected

□ Repository updated if necessary

---

## Documentation

□ ADR updated

□ Feature documentation updated

□ Roadmap updated if required

---

## Quality

□ Flutter analyze clean

□ Existing features unaffected

□ Naming follows Atlas standards

□ Reusable components created where appropriate

---

## User Experience

□ Easy to understand

□ Consistent with Atlas

□ Responsive

□ Accessible where practical

---

## Final Question

Does this feature make collecting easier, more enjoyable, or more meaningful?

If the answer is no...

Keep improving.
