# Atlas Premium Philosophy

## Guiding Principle

Basic helps collectors organize their collection.

Premium helps collectors understand their collection.

Atlas should never lock core collector functionality behind a paywall.

---

## Atlas Basic (Free)

✔ Secure Login
✔ Optional Two-Factor Authentication
✔ Barcode Scanning
✔ Unlimited Collections
✔ Manual Entry
✔ Vault Rooms
✔ Wishlist
✔ Search
✔ Collection Value
✔ Collection Health
✔ Collector Profile
✔ Basic Atlas Recommendations
✔ Cloud Sync

---

## Atlas Premium

✔ Atlas Intelligence+
✔ Advanced AI Recommendations
✔ Shelf / Photo Recognition
✔ Collection Analytics
✔ Seasonal Themes
✔ Custom Hero Backgrounds
✔ Advanced Reports (PDF/CSV)
✔ Backup & Restore History
✔ Collector Achievements

## Core Philosophy

Never remove essential collector features from Basic.

Premium should add intelligence, insights, personalization, and convenience—not create frustration.
