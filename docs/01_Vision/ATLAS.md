# Atlas Knowledge Philosophy
I don't want Atlas to just have words. I want Atlas to understand and decide for itself.
## Atlas Principle #3

**Atlas connects information instead of simply storing it.**

Traditional databases store facts.

Atlas builds knowledge.

Every collectible is connected to:

* Character
* Franchise
* Series
* Universe
* Retailer
* Convention
* Release Year
* Variants
* Related Collectibles

Atlas should be able to understand these relationships naturally.

This allows Atlas to answer questions without requiring custom filters for every possibility.

Example Questions

"Show me every Batman villain Pop."

"Which Justice League Pops am I missing?"

"Which Batman Pops were GameStop exclusives?"

"Show every Pop connected to The Dark Knight."

Atlas answers because it understands relationships.

# Atlas Golden Rules

Every feature added to Atlas should follow these rules.

1. Every scan teaches Atlas something.

2. Atlas never guesses when it can verify.

3. Atlas explains why it reached a conclusion.

4. Atlas remembers, so collectors don't have to.

5. Atlas connects knowledge instead of simply storing data.

6. The collector always owns their data.

7. Fast is a feature.

8. Trust is earned, never assumed.
