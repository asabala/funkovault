If you want to tighten the filter even further, here are three highly specific questions that often trip up product roadmaps in the collectibles and tracking space:

Does it scale with a massive collection?

Why it matters: A feature that feels awesome when a user has 10 items can become an absolute nightmare or a sluggish mess when they hit 500+ items. If it doesn't work at scale, it's a trap.

Does it automate the heavy lifting, or does it add homework?

Why it matters: Collectors love tracking, but they hate tedious manual data entry. If a feature requires them to manually input ten fields every time they update something, adoption will nose-dive. It needs to be low-effort, high-reward.

Does it provide a "single source of truth," or does it create noise?

Why it matters: In the data and value-tracking world, conflicting information kills trust. If you are introducing a new data stream or metric, it has to be incredibly reliable. If it introduces ambiguity, it hurts the platform.

How it looks together:
Does it help the collector?
Does it make Atlas smarter?
Will people actually use it?
Can we maintain it for years?
Does it work just as well for 500 items as it does for 5?
Does it save them time, or give them homework?
Does it protect the integrity of the data?
