# 📈 Atlas Market Timeline

## Feature Overview

Atlas Market Timeline is the historical record for every collectible stored within Atlas.

Unlike traditional collection apps that only display current information, Atlas preserves the complete story of every collectible throughout its lifetime.

Every collectible has a timeline.

Every timeline tells a story.

---

# Philosophy

Atlas is not simply a collection database.

Atlas is a collection intelligence platform.

Every collectible has a history.

Some histories are financial.

Some histories are personal.

Atlas preserves both.

---

# What Collectors See

When opening a collectible, collectors can scroll through a chronological timeline of important events.

Examples include:

📦 Added to Vault

💰 Estimated Value Updated

🏷 Sticker Added

⭐ Signed

🎯 Chase Confirmed

🛡 Protector Added

📥 Imported

🔄 Catalog Refreshed

📝 Personal Note Added

❤️ Collector Moment

🤖 Atlas Insight

Events are displayed from newest to oldest.

Collector Moments are intended to preserve memories that cannot be found anywhere else.

# Atlas Insights

Atlas automatically generates basic insights for all users.

Examples

"This collectible reached a new all-time high."

"You've owned this collectible for 2 years."

"This collectible has increased 24% since it was added."

"This collectible has never decreased in value."

Basic insights help collectors better understand their collection.
