# Atlas Constitution
### Version 1.0
### "Building Intelligence That Lasts"

# Purpose

Atlas is more than a collectibles application.

Atlas is an intelligence platform designed to transform observations into trusted knowledge, trusted knowledge into explainable decisions, and explainable decisions into meaningful collector intelligence.

Every architectural decision should strengthen this mission.

If a feature makes Atlas more intelligent, more explainable, more reusable, and easier to evolve, it belongs.

If it weakens those principles, it should be redesigned.

# Core Principles

## 1. Truth Before Convenience

Atlas never sacrifices accuracy for convenience.

Original observations are preserved.

Evidence is never discarded.

Decisions remain explainable.

---

## 2. Preserve Knowledge

Nothing valuable should be lost.

Observations become knowledge.

Knowledge becomes reusable.

Future engines should benefit from past discoveries.

---

## 3. Explain Every Decision

Atlas should always be able to answer:

Why?

Every important recommendation, warning, or comparison should include understandable reasoning.

---

## 4. Separate Responsibilities

Atlas separates:

- Observation from Identity
- Identity from Instance
- Instance from Ownership
- Ownership from Collection
- Decisions from Experiences

Each layer has a single responsibility.

---

## 5. Reusable Intelligence

Atlas should solve problems once.

Every engine should produce reusable intelligence that benefits the entire platform.

No duplicated business logic.

No duplicated rules.

---

## 6. Category Neutral

Atlas is never built around Funko.

Funko is simply the first language Atlas learns.

Every collectible category should integrate through adapters and policies rather than rewriting the platform.

---

## 7. Deterministic Whenever Possible

Given identical observations, policies, and versions, Atlas should produce identical conclusions.

Predictability builds trust.

---

## 8. Evidence Before Confidence

Confidence without evidence is an opinion.

Atlas values evidence first.

Confidence expresses certainty—not truth.

---

## 9. Engines Over Features

Atlas is built from engines—not screens.

Features come and go.

Engines remain reusable.

Every new capability should begin by identifying the responsible engine.

---

## 10. Experiences Stay Thin

Flutter is not the source of truth.

The web is not the source of truth.

Voice is not the source of truth.

Experiences present intelligence.

They do not create it.

---

Decision

No layer skips another.

No business rule belongs inside presentation code.

---

# Engineering Principles

When building Atlas, ask these questions first.

1. Which engine owns this responsibility?

2. Is this knowledge reusable elsewhere?

3. Can this decision be explained?

4. Is evidence preserved?

5. Does this duplicate existing logic?

6. Can another collectible category reuse this?

7. Will this still make sense five years from now?

If the answer is "no," redesign before implementing.
